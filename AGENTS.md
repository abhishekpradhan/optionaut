# This is NOT the Next.js you know

This version has breaking changes — APIs, conventions, and file structure may all differ from your training data. Read the relevant guide in `node_modules/next/dist/docs/` before writing any code. Heed deprecation notices.

# Project ground rules (the short version of PLAN.md + CONTRIBUTING.md)

1. **Never fetch, proxy, cache, or serve real market data** — not from Cboe,
   not from any API, not "just delayed." That architecture is decision D11
   (PLAN.md §10): exchanges license the display of real quotes, and there is
   no affordable legal path. The bundled market is fictional (generated by
   `src/lib/sim/market.ts`); anything real is user-supplied and lives only in
   their browser's localStorage.
2. **Educational only.** No brokerage links, no order flow, no signals or
   recommendations. Risk gets first-class placement, not fine print.
3. If you touch the simulated market or its generator, regenerate the
   fixtures in the same change: `node --experimental-strip-types
   scripts/generate-market.mjs` (deterministic; the refresh-calendar GitHub
   Action bumps its BASE_DATE monthly on its own).
4. The math in `src/lib/options/` stays tested — golden values, parity,
   finite differences, IV round-trips. `npm test` must be green.
5. One full-screen instrument, no document scroll (D8). New surfaces are
   views, overlays, or HUD elements. Entrances are CSS animations, never
   rAF-driven. Profit/loss is the CVD-validated blue↔red pair — color never
   carries meaning alone. No point-shaped background texture (dots read as
   chart data).
6. Every commit to `main` deploys to production. Treat it as live.
